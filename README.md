DeliMeals is a Flutter recipe app with ten food categories. You browse meals by category, open a recipe with ingredients and cooking steps, mark favorites and filter by diet. I built it in 2022 while following a Flutter course. All meal data is hardcoded in the app, so it needs no backend or API key.

---

## Why DeliMeals

The app is small and each screen has one job.

|  |  |
|---|---|
| <img src="docs/assets/readme/icons/layout-grid.svg" width="18" height="18" alt=""> **Categories first** | The home screen shows ten category tiles. Each opens a list of meals with duration, complexity and affordability. |
| <img src="docs/assets/readme/icons/heart.svg" width="18" height="18" alt=""> **Favorites** | A star on the recipe page adds the meal to a favorites tab. |
| <img src="docs/assets/readme/icons/sliders-horizontal.svg" width="18" height="18" alt=""> **Diet filters** | Gluten-free, lactose-free, vegetarian and vegan switches change which meals show up. |
| <img src="docs/assets/readme/icons/database.svg" width="18" height="18" alt=""> **Data in the app** | Ten meals and ten categories live in [lib/dummy_data.dart](lib/dummy_data.dart). Meal images load from remote URLs. |

## Features

- Named-route navigation with a tab bar and a drawer.
- State handled with plain setState in lib/main.dart.
- Raleway and RobotoCondensed fonts bundled under assets/fonts.
- Platform folders for Android, iOS, web, Linux, macOS and Windows.

## Quick start

```sh
flutter pub get
flutter run
```

Use flutter run -d <device> to pick a target.

### Requirements

- An older Flutter SDK that includes Dart 2. The pubspec pins the Dart SDK to ">=2.1.0 <3.0.0", so it needs an SDK that ships Dart 2. Current Flutter releases ship Dart 3.
- cupertino_icons is the sole package dependency.

## FAQ

<details>
<summary><b>Does it need a backend or API key?</b></summary>

No. All meal data is in lib/dummy_data.dart.
</details>

<details>
<summary><b>Which dietary filters exist?</b></summary>

Gluten-free, lactose-free, vegetarian and vegan.
</details>

<details>
<summary><b>Why will it not build on a recent Flutter?</b></summary>

The pubspec pins Dart below 3.0.0 and an old cupertino_icons version, and current Flutter releases ship Dart 3. Use an older SDK or migrate the pubspec.
</details>

<details>
<summary><b>Is it original work?</b></summary>

It was built while following a Flutter course, and the course handout PDF is kept in the repository.
</details>
